# ADR 0001: Apache License 2.0

- Status: approved
- Date: 2026-08-05
- Gate: G0
- Approved by: product owner

## Decision

License the project under Apache License 2.0.

## Rationale

It is permissive, supports broad personal and commercial adoption, and includes an explicit patent grant and contribution terms.

## Consequences

Distributions must comply with Apache-2.0 notice and attribution requirements. Dependencies and optional connectors remain subject to license compatibility review.
